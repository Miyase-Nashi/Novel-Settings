# 百合小说 · 设定集

可交互的 HTML 设定手册 —— 零依赖单文件，浏览器直接打开即可使用。

## 这是什么

为长篇百合小说搭建的设定管理工具：人物、世界观、情感线、学校、时间线……所有设定都结构化地收纳在一个 HTML 文件里，随时打开、随手增改。

## 功能一览

- **三级结构**：模块 → 分组 → 条目，可自由增减
- **人物卡（完整版）**：约 40 项字段，覆盖人物简介、形象、家庭、性格、社会关系等
- **简洁人物卡**：名字 + 1:1 头像 + 8 项短字段（昵称 / 性别 / 出身 / 生日 / 年龄 / 身高 / 性取向 / 个人简述），适合速览
- **横版人物卡**：左 1:1 头像 + 右速览信息（性别 / 出身 / 所属 / 生日 / 年龄 / 身高 / 性取向 / 个人简述，**去掉「昵称」、新增「所属」**）；可一键导出**银行卡比例（≈1.586:1）**的 PNG 图片，方便做立绘卡 / 人设卡
- **三级排序**：模块、分组、条目都可在「编辑」态用 ▲▼ 调整顺序
- **图片上传**：条目配图与 1:1 头像（自动居中裁剪并压缩为 512×512，保持文件轻量）
- **本地自动保存**：编辑内容自动存入浏览器缓存，刷新不丢
- **导入导出**：一键「保存 HTML」（把最新数据内嵌进文件后下载），也可导出 / 导入 JSON 备份

## 怎么用

1. 用浏览器打开 `index.html`
2. 点右上角 **✎ 编辑**，开启编辑模式
3. 在侧边栏增删模块、分组；在卡片上增删条目、上传头像、改字段
4. 编辑态下，用各条目 / 分组 / 模块右侧的 **▲ / ▼** 调整顺序
5. 完成后点 **💾 保存 HTML**，下载最新版（数据已内嵌其中）

> 阅读模式下所有内容只读、不可误改；开启编辑后才会出现增删与排序按钮。

## 在线预览（GitHub Pages）

仓库开启 Pages 后即可在线访问：

1. 进入仓库 **Settings → Pages**
2. Branch 选择 `main`、目录选 `(root)`
3. 点 **Save**，稍候即可获得一个 `https://Miyase-Nashi.github.io/Novel-Settings/` 的访问地址

> 纯前端单文件，无需任何后端或构建步骤。
